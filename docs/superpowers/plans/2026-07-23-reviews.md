# Reviews Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the responsive Reviews section from the English Excellence design.

**Architecture:** Keep the section isolated in its existing HTML partial and CSS file. Use a semantic list and CSS Grid to show one, two, or three cards at the project breakpoints without JavaScript.

**Tech Stack:** HTML5, CSS, Vite, responsive WebP images

## Global Constraints

- Support fluid layouts from 320px.
- Use breakpoints at 375px, 768px, and 1280px.
- Use “What our students say” as the heading.
- Store lowercase image files in `src/images`.
- Keep the existing project container and CSS entry-file conventions.
- Do not modify unrelated sections.
