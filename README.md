# Top Coders

Top Coders - це адаптивний односторінковий навчальний вебсайт для школи
англійської мови. Проєкт створений на Vite та реалізований на HTML, CSS і
JavaScript.

## About Project

Сайт знайомить користувача з перевагами школи, командою викладачів, відгуками
студентів та формою для залишення заявки. У проєкті використано анімації появи
блоків, мобільне меню, слайдер відгуків Swiper і готову конфігурацію для деплою
на GitHub Pages.

## Features

- адаптивна верстка для mobile, tablet і desktop
- мобільне меню з оверлеєм
- секція відгуків на Swiper
- scroll-анімації для окремих блоків
- форма заявки з кастомною візуалізацією
- готовий деплой на GitHub Pages
